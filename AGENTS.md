# BINTRACK Flutter

- Este repositorio contiene la aplicación Flutter. El backend Django vive en
  `C:\proyectos\BINTRACK`.
- No incluir secretos, credenciales o URL con tokens en el código, Git o docs.
- La URL del backend se define al compilar con `API_HOST`; no dejar direcciones
  LAN como destino de una compilación distribuible.
- Antes de generar APK para usuarios, probar el flujo contra el entorno
  correspondiente y confirmar la rama de backend desplegada.
- Consultar `C:\proyectos\BINTRACK\docs\CONTEXTO_BINTRACK.md` para las
  decisiones de producción, suscripciones y despliegue.
